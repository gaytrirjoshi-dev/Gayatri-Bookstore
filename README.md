# 📚 Gayatri Bookstore - Full Stack Java Application

A complete Online Bookstore Management System built using **Java Full Stack**. Users can browse books, add to cart, and place orders. Admin can manage inventory, users, and orders.


### ✨ Key Features

**User Module:**
- 🔐 Secure User Registration & Login (Spring Security)
- 📖 Browse Books with Categories & Search Filters
- 🔍 Search by Title, Author
- 🛒 Shopping Cart & Wishlist
- 💳 Order Placement & Order History
- ⭐ Book Reviews & Ratings

### 🛠️ Tech Stack

**Backend:**
- Java 17
- Spring Boot 3.x
- Spring Security + JWT Authentication
- Spring Data JPA (Hibernate)
- RESTful APIs
- Maven

**Frontend:**
- React.js / Reactvite
- HTML5, CSS3, Bootstrap / Tailwind CSS
- JavaScript

**Database:**
-  PostgreSQL

**Tools & Others:**
- Git & GitHub
- Postman for API Testing
- Vs Code
